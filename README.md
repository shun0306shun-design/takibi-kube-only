# 焚き火くべ

片手・無心で薪をくべて火を育てる、スマホ専用のブラウザアプリです。
通信・課金・広告・アカウントは一切なし。記録は端末の localStorage にだけ保存します。

ひと息だけ火を眺めてもいいし、ひと晩かけて熾を育ててもいい。やめても途切れても、何も失いません。

## 起動手順

ビルド不要です。このフォルダを静的ファイルとして開くだけで動きます。

**スマホで遊ぶ（おすすめ）**

1. PCでこのフォルダに移動して簡易サーバーを起動
   ```
   cd takibi-kube-only
   python3 -m http.server 8000
   ```
2. 同じWi-Fiにつないだスマホのブラウザで `http://<PCのIPアドレス>:8000/` を開く
3. ブラウザの「ホーム画面に追加」をすると、全画面のアプリとして起動できます

GitHub Pages などの静的ホスティングにフォルダごと置いても同じように動きます。

**PCで動作確認だけする**

`index.html` をダブルクリックし、ブラウザの開発者ツールでスマホ表示（縦向き）にします。

> 記録は「開いたURLごと・ブラウザごと」に別々に保存されます。

## 使い方

### 基本

- **薪をくべる**：画面のどこか、または下の「くべる」ボタンをタップ。長押しで連続してくべられます
- **火力**：火は時間とともに小さくなります。「くべる」ボタンの外周リングが今の火力です
  （熾火 → 種火 → 小さな火 → 焚き火 → 大きな焚き火 → 天を焦がす炎）
- **中断**：アプリを閉じても熾火は消えません。戻ると「留守のあいだに」として、離れていた間の様子を短く知らせます
- **下のボタン**

  | ボタン | はたらき |
  | --- | --- |
  | 図鑑 | 出来事・薪・あぶり・おみやげ・しおり の各ページと、できごとログ |
  | 空 | 自動 → 夜 → 朝 の切り替え（自動は 5:00〜16:59 が朝）。押すと今夜の月の名前も出ます |
  | 音 | 音全体の ON / OFF（**初期状態は OFF**） |
  | 設定 | 演出・表示・音・空・天気・タイマー・記録など |

### はじめは火とボタンだけ

新しく始めたときに見えるのは、火と下のボタンだけです。遊ぶうちに、くべるボタンの上の小さなボタン（チップ）が1つずつひらきます。
ひらく前でも中身（確率など）は同じで、ボタンが見えないだけです。すでに遊んでいる記録では、最初から全部ひらいています。

| ひらくもの | きっかけ |
| --- | --- |
| 薪の種類 | くべた薪 10本 |
| あぶる | 20本、かつ「小さな火」に届いたことがある |
| ながめる・しおり | 30本 |
| 写真 | 50本 |
| 組み方 | 100本 |
| 熾の表示 | 熾がはじめて10を超えた |

設定の「表示：すっきり」にすると、チップや上部の文字を隠して、火と本数だけの画面になります（隠した機能は設定の「火のしたく」から使えます）。
設定のいちばん下の「あそびかた」に、ひらいた機能の短い説明があります。

### 演出のつよさ（しずか／にぎやか）

設定のいちばん上で選べます。**しずか は見た目・音・振動の強さだけを変えます。確率・記録・できることは、にぎやかとまったく同じです。**

| 場面 | しずか のとき |
| --- | --- |
| レアの登場（★★・★★★） | スローモーションと画面の揺れなし。明るくなるのはごく弱く。効果音は2音まで |
| くべコンボ | 数字を出さない。音程の上昇と節目の弾けなし（最高コンボの記録は続く） |
| 業火タイム | 中身（15秒・確率3倍）は同じ。知らせは上部の小さな「業火」の文字だけ。炎はうっすら金色 |
| 予兆 | 色は同じ。光は弱く短い。火の粉は止まらない |
| 金の薪・節目 | トーストとやわらかい光だけ。花火と爆発音なし |
| 振動 | くべたときの短い1回だけ |

既定は にぎやか です。端末が「視差効果を減らす」設定のときだけ、初期値が しずか になります。

### ながめる（おまかせ火の番）

チップ「ながめる」から 15分／30分／60分 を選ぶと、何もしなくても火が続きます。

- 火力が下がると、おまかせで薪を1本くべます（4秒に1本まで）。火は「焚き火」のあたりで静かに続きます
- **おまかせの薪は、手でくべた薪とは別に数えます**（設定のきろく「おまかせでくべた薪」）。くべた薪の本数・コンボ・今日の一本・薪の図鑑・節目には入りません
- 始まると下のボタンとチップが消え、上部に残り時間だけが出ます。画面をタップすると操作が5秒もどります（その1回目のタップでは薪をくべません）
- 対応している端末では、その間、画面が自動で消えないようにします（設定で OFF にできます）。使えない端末では、そのまま続きます
- 1回は最長60分です。時間が来ると「火の番を終わりました」と出て、火は自然に小さくなります
- 寝落ちタイマーを入れたときも、残り時間が3割を切るまで、おまかせ火の番が働きます

### 薪の種類と組み方

| 薪 | 燃え方 |
| --- | --- |
| 杉 | 火つきがよく、パチパチとにぎやかにはぜる |
| 桜 | 甘い香りの煙が、淡い桜色のもやになって漂う |
| 松ぼっくり | 一気に燃え上がるが、すぐに落ち着く |
| 流木 | 炎がしばらく青みがかる |
| 樫 | 火力はゆっくり、長くもつ |
| 竹 | 少しおいて、パン！とはぜる |

| 組み方 | 炎 | 薪1本の火力 | 減り | 火の粉 | 熾のたまり | 向いている遊び方 |
| --- | --- | --- | --- | --- | --- | --- |
| 合掌型 | ふだんの形 | ×1 | ×1 | ×1 | ×1 | ふだん |
| 井桁型 | 高く太い | ×1.25 | ×1.35 | ×1.3 | ×0.7 | すぐ大きな火にしたい |
| 並列型 | 低く横に広い | ×1 | ×0.7 | ×0.7 | ×1.5 | ゆっくり長く、熾を育てる |

並列型は、あぶりの焼ける速さが×0.8になります（食べごろを狙いやすい）。**組み方でレアの確率は変わりません。**

### 熾（おき）と、うめて焼く

- **熾**は、ほどよい火を保つとゆっくりたまる2つ目の量です（火の状態の下の ●●●○○）
  - 「焚き火」〜「大きな焚き火」を保つと約8分で満ちます。「小さな火」と「天を焦がす炎」では半分の速さです
  - 火が熾火まで落ちると、約6時間かけて減っていきます
  - 薪の減りが最大35%ゆっくりになり、熾火からの最初の1本で火がつきやすくなります
- **あぶる**：串を火にかざし、いい焼き色になったら画面をタップ。結果は「生焼け／こんがり／完璧／黒焦げ」
- **うめて焼く**：熾が40以上あると、あぶるの選択に「うめる」が出ます（焼き栗＝目安8分／焼きりんご＝12分／ホイル焼き芋＝20分）
  - 実際の時間で進み、アプリを閉じていても進みます。熾が少ないと遅くなり、尽きると止まるだけです
  - 「ほりだす」と結果が出ます（まだ硬い／ほくほく／最高／炭）。最高の幅は広く、時計を見張る必要はありません
  - 食べごろになると、うめた場所から淡い湯気が立ち、あぶるチップがほんのり光ります

### 訪問者となかよく

会った回数でなかよし度が4段階に上がります。火の近くに座って長くいるようになり、帰りぎわにおみやげを置いていきます（全15種。図鑑「おみやげ」）。
いちばんなかよくなると、しぐさが1つ増えます。**来る確率は変わりません。**

### 天気・季節・月

- 天気（晴れ・雨・雪・霧）は数分〜十数分ごとに変わります。雨の日は薪の減りが少し早く、雪の日は景色が白くなります。設定で固定もできます
- 季節は端末の日付で決まります（春：花びら／夏：夜に蛍／秋：落ち葉／冬：雪景色）
- 月は今夜の本当の形になります（日付から計算。通信はしません）。新月のころは星が増えて天の川がうっすら見え、満月のころは夜の地面がほんのり明るくなります

### しおりと小物

図鑑の「しおり」に、やってみたいことが18個あります。期限・順番・日替わりはありません。
うまった数に応じて、焚き火のまわりに小物（丸太のいす・やかん・ランタン・マグカップ・薪棚・小さなテント）が増え、しおりのページで出し入れできます。

### 気持ちよさの仕掛け

- **くべコンボ**：0.3〜0.8秒の間隔で指でくべ続けると続きます。10・30・50・100 で火の粉が弾けます（長押しとおまかせの薪は数えません）
- **業火タイム**：「天を焦がす炎」を約40秒保つと、15秒間、**レアな出来事の確率が3倍**になります
- **予兆**：レアの直前に、まれに火元が色つきで光ります。白 ＜ 青 ＜ 赤 ＜ 金（★★以上が確定）＜ 虹（★★★が確定）。確率は変えません
- **金の薪**：手でくべるたびに 1/500 で、次の一本が金色に光ります
- **節目**：累計 100・1,000・10,000 本と、ゾロ目でお祝い
- **今日の一本・称号**：連続日数と、累計本数に応じた称号。途切れても何も失いません

### そのほか

- **寝落ちモード**：15分／30分／60分。時間に向けて火と音をゆっくり小さくし、最後は熾火と静かな画面になります
- **音のミックス**：焚き火・川・虫の声・風・雨を、それぞれ ON/OFF と音量で調整できます
- **写真モード**：UIを隠し、もう一度タップで「くべた薪 ○本」・日付・月の名前を小さく入れた画像を保存・共有できます

### 確率に関わる決まり（このアップデートでの変更）

既存のレアの確率は変えていません。変わったのは次の点だけです。

| 場面 | 変更 |
| --- | --- |
| おまかせ火の番が働いている間（ながめる中と、寝落ちタイマーの前半） | 燃えている間の抽選が **20秒ごと**（ふだんの半分の頻度）になります。1回あたりの確率は同じです。「？？？」の2つは起きません |
| おまかせの薪 | くべたときのレア抽選と、金の薪の抽選を行いません |
| 新しいレア | 天の川・月暈（各1%、条件は表のとおり） |
| 演出のつよさ・組み方・すっきり表示・少しずつひらく・画質の自動調整 | 確率には一切影響しません |

## データについて

- 保存先はブラウザの localStorage（キー：`takibi-kube.v1`）のみ。外部には何も送信しません
- 以前のバージョンの記録はそのまま引き継がれます（新しい項目は、足りないときだけ初期値で補います）
- どんな演出・機能でも、くべた本数や図鑑などの記録が消えたり減ったりすることはありません

### 記録を手元に残す（書き出し・読み込み）

記録は端末のブラウザの中にしかありません。**iPhone の Safari は、ホーム画面に追加していないサイトの記録を、しばらく開かないと消すことがあります。** 長く遊んだら、書き出しておくと安心です。

- **設定 → きろく →「記録を書き出す」**：記録を `TKB1.` で始まる1行の文字列にします。コピーするか、ファイル（`takibi-kiroku-日付.txt`）として保存・共有できます
- **「記録を読み込む」**：文字列を貼りつけ →「たしかめる」で本数・図鑑の数・書き出した日を確認 → 2回タップで置き換えます
  - 形式が合わない・壊れている・大きすぎる（200KB超）文字列は「読み込めませんでした」と出て、何も変わりません
  - 置き換える直前の記録は1世代だけ控え（`takibi-kube.v1.bak`）に残り、「ひとつ前の記録に戻す」で戻せます
- 書き出しには、寝落ちタイマーやながめるなど、その場かぎりの状態は含まれません
- 設定 →「記録をすべて消す」でいつでも初期化できます（2回タップ。控えもいっしょに消えます）

### 保存される項目

火力・くべた本数・燃やした時間・図鑑（出来事／薪／あぶり／おみやげ／しおり）・ログ・天気・連続日数・最高コンボ・設定（音・ミックス・振動・空・天気・炎の色）に加えて、このアップデートで次の項目が増えました（合計で数KB以内）。

`set.calm`（演出）／`set.view`（表示）／`set.wake`（画面をつけたままにする）／`watchLogs`（おまかせでくべた薪）／`open`（ひらいた機能）／`peak`（いちばん大きかった火力）／`news2`・`a2hs`（1回だけの案内を見せた印）／`ember`（熾）／`bury`（うめたもの）／`stack`・`stackRec`（組み方と記録）／`gifts`（おみやげ）／`colorFree`（炎の色の解放）／`shiori`・`props`・`prog`（しおり・小物・途中経過）

課金・広告・ガチャ・リセットチケットの類はありません。

## 動作について

- 画面の更新は毎秒60回まで（シートを開いている間・ながめる中・眠ったあとは毎秒30回）
- 端末が重いときは、炎・火の粉・煙・天気の粒の「出る量」だけを自動で絞ります（火力・抽選・記録には影響しません。何も表示しません）
- 画面を消さない機能（Screen Wake Lock）、共有（Web Share）、クリップボード、保存の永続化の依頼（Storage API）、振動は、使える端末でだけ使います。使えなくても遊べます
- オフライン対応（Service Worker）・通知・バックグラウンド再生・位置情報は使っていません

## 開発メモ

URLの末尾に `?debug` を付けると、ブラウザのコンソールから演出や状態を確認できます（プレビューは図鑑に記録されません）。

- `takibi.ids`：`takibi.fx(id)` で出せるIDの一覧
  - レアな出来事のID、`wood-cedar` など、`roast-marsh` / `roast-imo`、`bury-best` など、`wx-rain` / `wx-snow` / `wx-fog` / `wx-clear`、`season-spring` など
  - `fever`、`combo`、`milestone`、`gold`、`omen-white` 〜 `omen-rainbow`、`calm-on` / `calm-off`
  - `watch` / `watch-end`、`sleep`（20秒の短縮版）、`photo`、`away`、`news`、`a2hs`
  - `stack-igeta` など、`friend-kitsune` など（いちばんなかよくなったときのしぐさ）、`gift`、`shiori`、`props-all` / `props-none`
  - `open-all` / `open-none`（少しずつひらく）、`q-low` / `q-auto`（画質の段階）
  - `continue`、`gameover`（`gameover` のプレビューは画面を5回タップすると抜けられます）
- `takibi.fuel(0〜100)` / `takibi.ember(0〜100)`：火力・熾を指定
- `takibi.skip(分)`：時計を進める（その間アプリを閉じていたものとして扱う）。負の値で時計を戻せます
- `takibi.moon(0〜1)`：月の形を指定（0＝新月、0.25＝上弦、0.5＝満月、0.75＝下弦。`null` で元に戻す）
- `takibi.pick('log')` / `takibi.pick('amb')`：抽選を1回だけ行ってIDを返す（確率の確認用。何も起こしません）
- `takibi.counts()`：fps・画質の段階・粒子数・キャンバスの数・保存データの大きさなど
