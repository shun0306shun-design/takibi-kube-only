# 焚き火くべ

片手・無心で薪をくべて火を育てる、スマホ専用のブラウザアプリです。
通信・課金・広告・アカウントは一切なし。記録は端末の localStorage にだけ保存します。

## 起動手順

ビルド不要です。このフォルダを静的ファイルとして開くだけで動きます。

**スマホで遊ぶ（おすすめ）**

1. PCでこのフォルダに移動して簡易サーバーを起動
   ```
   cd takibi-kube-only
   python3 -m http.server 8000
   ```
2. 同じWi-Fiにつないだスマホのブラウザで `http://<PCのIPアドレス>:8000/` を開く
3. ブラウザの「ホーム画面に追加」をすると、全画面のアプリとして起動できます

GitHub Pages などの静的ホスティングにフォルダごと置いても同じように動きます。

**PCで動作確認だけする**

`index.html` をダブルクリックし、ブラウザの開発者ツールでスマホ表示（縦向き）にします。

> 記録は「開いたURLごと・ブラウザごと」に別々に保存されます。

## 使い方

### 基本

- **薪をくべる**：画面のどこか、または下の「くべる」ボタンをタップ。長押しで連続してくべられます
- **火力**：火は時間とともに小さくなります。「くべる」ボタンの外周リングが今の火力です
  （熾火 → 種火 → 小さな火 → 焚き火 → 大きな焚き火 → 天を焦がす炎）
- **中断**：アプリを閉じても熾火は消えません。戻ると「留守のあいだに」として、離れていた間の火の様子と、来ていた訪問者を短く知らせます
- **下のボタン**（すべて親指の届く位置）

  | ボタン | はたらき |
  | --- | --- |
  | 図鑑 | 「出来事」「薪」「あぶり」の3ページと、できごとログ |
  | 空 | 自動 → 夜 → 朝 の切り替え（自動は 5:00〜16:59 が朝、それ以外が夜） |
  | 音 | 音全体の ON / OFF（**初期状態は OFF**） |
  | 設定 | 音・振動・空・天気・寝落ちタイマー・音のミックス・炎の色・記録 |

- **くべるボタンの上の小さなボタン**

  | ボタン | はたらき |
  | --- | --- |
  | 薪：○○ | タップするたびに薪の種類を切り替え（おまかせ＝毎回ランダム） |
  | あぶる | マシュマロか焼き芋をあぶる（「小さな火」以上のときだけ出ます） |
  | 写真 | 写真モード |

### 薪の種類

| 薪 | 燃え方 |
| --- | --- |
| 杉 | 火つきがよく、パチパチとにぎやかにはぜる |
| 桜 | 甘い香りの煙が、淡い桜色のもやになって漂う |
| 松ぼっくり | 一気に燃え上がるが、すぐに落ち着く |
| 流木 | 炎がしばらく青みがかる |
| 樫 | 火力はゆっくり、長くもつ |
| 竹 | 少しおいて、パン！とはぜる |

初めて使った種類と、種類ごとにくべた本数が図鑑の「薪」に残ります。

### 火であぶる

串を火にかざし、いい焼き色になったら画面をタップして引き上げます。
結果は「生焼け／こんがり／完璧／黒焦げ」。火が強いほど早く焼け、放っておくと焦げます。焦げも含めて図鑑の「あぶり」に残ります。

### 天気と季節

- 天気（晴れ・雨・雪・霧）は数分〜十数分ごとに変わります。雨の日は薪の減りが少し早く、雪の日は景色が白くなります。設定で固定もできます
- 季節は端末の日付で決まります（春：花びら／夏：夜に蛍／秋：落ち葉／冬：雪景色）

### 気持ちよさの仕掛け

- **くべコンボ**：0.3〜0.8秒の間隔で指でくべ続けるとコンボが続き、音程と火の粉が増えます。10・30・50・100 で火の粉が弾けます（長押しの連続くべは数えません）
- **業火タイム**：「天を焦がす炎」を保つと、リングの外側の細い金色のゲージがたまります（約40秒）。満タンで15秒間、炎が金色になり、**レアな出来事の確率が3倍**になります
- **予兆**：レアの直前に、まれに火元が色つきで光ります。白 ＜ 青 ＜ 赤 ＜ 金（★★以上が確定）＜ 虹（★★★が確定）。白・青・赤は何も起きないこともあります。予兆は決まった結果を先に見せるだけで、確率は変えません
- **金の薪**：くべるたびに 1/500 で、次の一本が金色に光ります。くべると火力が満タンになります
- **節目**：累計 100・1,000・10,000 本と、777 や 1,111 のようなゾロ目でお祝いの花火が上がります
- **今日の一本**：その日に1本でもくべると連続日数が伸びます。途切れても何も失いません（表示だけ）
- **称号**：累計本数に応じて変わります（100本・1,000本・10,000本…）

### そのほか

- **寝落ちモード**：設定で 15分／30分／60分。時間に向けて火と音をゆっくり小さくし、最後は熾火と静かな画面になります。残り時間は画面上部に小さく出ます。眠ったあとは画面タップで元に戻ります
- **音のミックス**：焚き火・川・虫の声・風・雨（雨の日だけ）を、それぞれ ON/OFF と音量で調整できます。下の「音」が OFF のあいだは何も鳴りません
- **写真モード**：UIをすべて隠します。画面をタップすると、その景色に「くべた薪 ○本」と日付を小さく入れた画像を作り、共有または保存できます

## レアな出来事（全22種）

出会うと図鑑（種類・回数・初めて出会った日時）とログ（直近100件）に残ります。
★★ は画面がふわっと明るくなり、★★★ は一瞬のスローモーションと小さな揺れがつきます。

| 出来事 | 出会える条件 | 1回の抽選あたり |
| --- | --- | --- |
| 青い炎 ★ / 翠の炎 ★ / 紫の炎 ★★ / 桜色の炎 ★★ / 虹色の炎 ★★★ | 薪をくべたとき | 0.5% / 0.4% / 0.2% / 0.15% / 0.03% |
| 火の粉花火 ★ / 大輪の花火 ★★★ | 薪をくべたとき（大輪は大きな火のときだけ） | 0.4% / 0.05% |
| 流れ星 ★ / 流星群 ★★★ | 夜、火が燃えている間 | 3% / 0.15% |
| 朝の虹 ★★ / 朝露の精霊 ★★★ | 朝、火が燃えている間 | 1% / 0.3% |
| 火の精霊 ★★ | 「焚き火」以上に育った火のそばに | 1% |
| キツネ ★ / フクロウ ★★ | 夜の訪問者 | 1.2% / 0.5%（※） |
| 猫 ★ | 朝の訪問者 | 1.2%（※） |
| 旅人 ★★ / 白い鹿 ★★★ | 夜も朝も来る訪問者 | 0.4% / 0.12%（※） |
| 月虹 ★★★ | 夜、雨が上がってから5分のあいだ | 2% |
| ダイヤモンドダスト ★★ | 雪景色の朝（雨・霧でないとき） | 0.6% |
| 金の薪 ★★ | 薪をくべるたびに | 1/500 |
| ？？？ ★★★☆ | ？？？ | 1/8192 |
| ？？？ ★★★★ | ？？？ | 1/16384 |

- 抽選は「薪をくべたとき（連打しても毎秒1回まで）」と「火が燃えている間の10秒ごと」です
- （※）訪問者は火が大きいほど来やすくなります。表は火力が最大のときの値で、火力に応じて 0.4〜1.0 倍になります
- **業火タイム中は、上の確率がすべて3倍になります**（金の薪と「？？？」の2つは変わりません）
- 「？？？」の2つは出会うまで中身がわかりません。どちらも1日に1回まで、同じ日に両方は起きません。図鑑の「出来事」を「？？？ ★★★★」以外すべて埋めると、設定で炎の色を自由に選べるようになります

## データについて

- 保存先はブラウザの localStorage（キー：`takibi-kube.v1`）のみ。外部には何も送信しません
- 以前のバージョンの記録はそのまま引き継がれます（新しい項目は、足りないときだけ初期値で補います）
- 保存されるもの：火力、くべた本数、図鑑（出来事・薪・あぶり）、ログ、天気、連続日数、最高コンボ、設定（音・ミックス・振動・空・天気・炎の色）
- 寝落ちタイマーは保存されません（その場かぎり）
- どんな演出が起きても、くべた本数や図鑑などの記録が消えたり減ったりすることはありません
- 設定 →「記録をすべて消す」でいつでも無料で初期化できます（2回タップで実行）
- 課金・広告・ガチャ・リセットチケットの類はありません

## 開発メモ

URLの末尾に `?debug` を付けると、ブラウザのコンソールから演出をプレビューできます（図鑑には記録されません）。

- `takibi.ids`：プレビューできるIDの一覧
- `takibi.fx('rainbow')`：演出を出す。レアな出来事のほか、次のようなIDがあります
  - `wood-cedar` などの薪、`roast-marsh` / `roast-imo`、`wx-rain` / `wx-snow` / `wx-fog` / `wx-clear`、`season-spring` など
  - `fever`、`combo`、`milestone`、`gold`、`omen-white` 〜 `omen-rainbow`、`away`、`sleep`（20秒の短縮版）、`photo`
  - `continue`、`gameover`（`gameover` のプレビューは画面を5回タップすると抜けられます）
- `takibi.pick('log')` / `takibi.pick('amb')`：抽選を1回だけ行ってIDを返す（確率の確認用。何も起こしません）
