# 焚き火くべ

片手・無心で薪をくべて火を育てる、スマホ専用のブラウザアプリです。
課金・広告・アカウント登録は一切なし。**ひとりの焚き火は通信なし**で、記録は端末の localStorage にだけ保存します。
合言葉で入る「部屋」に入ったときだけ、Firebase と通信します（送るのは数字と番号、それと入れた場合は6文字までの呼び名だけ。くわしくは「部屋（囲む火）」）。

ひと息だけ火を眺めてもいいし、ひと晩かけて熾を育ててもいい。やめても途切れても、何も失いません。

## 起動手順

ビルド不要です。このフォルダを静的ファイルとして開くだけで動きます。

**スマホで遊ぶ（おすすめ）**

1. PCでこのフォルダに移動して簡易サーバーを起動
   ```
   cd takibi-kube-only
   python3 -m http.server 8000
   ```
2. 同じWi-Fiにつないだスマホのブラウザで `http://<PCのIPアドレス>:8000/` を開く
3. ブラウザの「ホーム画面に追加」をすると、全画面のアプリとして起動できます

GitHub Pages などの静的ホスティングにフォルダごと置いても同じように動きます。

**PCで動作確認だけする**

`index.html` をダブルクリックし、ブラウザの開発者ツールでスマホ表示（縦向き）にします。

> 記録は「開いたURLごと・ブラウザごと」に別々に保存されます。

## 使い方

### 基本

- **薪をくべる**：画面のどこか、または下の「くべる」ボタンをタップ。長押しで連続してくべられます
- **火力**：火は時間とともに小さくなります。「くべる」ボタンの外周リングが今の火力です
  （熾火 → 種火 → 小さな火 → 焚き火 → 大きな焚き火 → 天を焦がす炎）
- **中断**：アプリを閉じても熾火は消えません。戻ると「留守のあいだに」として、離れていた間の様子を短く知らせます
- **下のボタン**

  | ボタン | はたらき |
  | --- | --- |
  | 図鑑 | 出来事・薪・あぶり・おみやげ・しおり の各ページと、できごとログ |
  | 空 | 自動 → 夜 → 朝 の切り替え（自動は 5:00〜16:59 が朝）。押すと今夜の月の名前も出ます |
  | 音 | 音全体の ON / OFF（**初期状態は OFF**） |
  | 設定 | 演出・表示・音・空・天気・タイマー・記録など |

### はじめは火とボタンだけ

新しく始めたときに見えるのは、火と下のボタンだけです。遊ぶうちに、くべるボタンの上の小さなボタン（チップ）が1つずつひらきます。
ひらく前でも中身（確率など）は同じで、ボタンが見えないだけです。すでに遊んでいる記録では、最初から全部ひらいています。

| ひらくもの | きっかけ |
| --- | --- |
| 薪の種類 | くべた薪 10本 |
| あぶる | 20本、かつ「小さな火」に届いたことがある |
| ながめる・しおり | 30本 |
| 写真 | 50本 |
| 組み方 | 100本 |
| 熾の表示 | 熾がはじめて10を超えた |

設定の「表示：すっきり」にすると、チップや上部の文字を隠して、火と本数だけの画面になります（隠した機能は設定の「火のしたく」から使えます）。
設定のいちばん下の「あそびかた」に、ひらいた機能の短い説明があります。

### 演出のつよさ（しずか／にぎやか）

設定のいちばん上で選べます。**しずか は見た目・音・振動の強さだけを変えます。確率・記録・できることは、にぎやかとまったく同じです。**

| 場面 | しずか のとき |
| --- | --- |
| レアの登場（★★・★★★） | スローモーションと画面の揺れなし。明るくなるのはごく弱く。効果音は2音まで |
| くべコンボ | 数字を出さない。音程の上昇と節目の弾けなし（最高コンボの記録は続く） |
| 業火タイム | 中身（15秒・確率3倍）は同じ。知らせは上部の小さな「業火」の文字だけ。炎はうっすら金色 |
| 予兆 | 色は同じ。光は弱く短い。火の粉は止まらない |
| 金の薪・節目 | トーストとやわらかい光だけ。花火と爆発音なし |
| 振動 | くべたときの短い1回だけ |

既定は にぎやか です。端末が「視差効果を減らす」設定のときだけ、初期値が しずか になります。

### ながめる（おまかせ火の番）

チップ「ながめる」から 15分／30分／60分 を選ぶと、何もしなくても火が続きます。

- 火力が下がると、おまかせで薪を1本くべます（4秒に1本まで）。火は「焚き火」のあたりで静かに続きます
- **おまかせの薪は、手でくべた薪とは別に数えます**（設定のきろく「おまかせでくべた薪」）。くべた薪の本数・コンボ・今日の一本・薪の図鑑・節目には入りません
- 始まると下のボタンとチップが消え、上部に残り時間だけが出ます。画面をタップすると操作が5秒もどります（その1回目のタップでは薪をくべません）
- 対応している端末では、その間、画面が自動で消えないようにします（設定で OFF にできます）。使えない端末では、そのまま続きます
- 1回は最長60分です。時間が来ると「火の番を終わりました」と出て、火は自然に小さくなります
- 寝落ちタイマーを入れたときも、残り時間が3割を切るまで、おまかせ火の番が働きます

### 薪の種類と組み方

| 薪 | 燃え方 |
| --- | --- |
| 杉 | 火つきがよく、パチパチとにぎやかにはぜる |
| 桜 | 甘い香りの煙が、淡い桜色のもやになって漂う |
| 松ぼっくり | 一気に燃え上がるが、すぐに落ち着く |
| 流木 | 炎がしばらく青みがかる |
| 樫 | 火力はゆっくり、長くもつ |
| 竹 | 少しおいて、パン！とはぜる |

| 組み方 | 炎 | 薪1本の火力 | 減り | 火の粉 | 熾のたまり | 向いている遊び方 |
| --- | --- | --- | --- | --- | --- | --- |
| 合掌型 | ふだんの形 | ×1 | ×1 | ×1 | ×1 | ふだん |
| 井桁型 | 高く太い | ×1.25 | ×1.35 | ×1.3 | ×0.7 | すぐ大きな火にしたい |
| 並列型 | 低く横に広い | ×1 | ×0.7 | ×0.7 | ×1.5 | ゆっくり長く、熾を育てる |

並列型は、あぶりの焼ける速さが×0.8になります（食べごろを狙いやすい）。**組み方でレアの確率は変わりません。**

### 熾（おき）と、うめて焼く

- **熾**は、ほどよい火を保つとゆっくりたまる2つ目の量です（火の状態の下の ●●●○○）
  - 「焚き火」〜「大きな焚き火」を保つと約8分で満ちます。「小さな火」と「天を焦がす炎」では半分の速さです
  - 火が熾火まで落ちると、約6時間かけて減っていきます
  - 薪の減りが最大35%ゆっくりになり、熾火からの最初の1本で火がつきやすくなります
- **あぶる**：串を火にかざし、いい焼き色になったら画面をタップ。結果は「生焼け／こんがり／完璧／黒焦げ」
- **うめて焼く**：熾が40以上あると、あぶるの選択に「うめる」が出ます（焼き栗＝目安8分／焼きりんご＝12分／ホイル焼き芋＝20分）
  - 実際の時間で進み、アプリを閉じていても進みます。熾が少ないと遅くなり、尽きると止まるだけです
  - 「ほりだす」と結果が出ます（まだ硬い／ほくほく／最高／炭）。最高の幅は広く、時計を見張る必要はありません
  - 食べごろになると、うめた場所から淡い湯気が立ち、あぶるチップがほんのり光ります

### 訪問者となかよく

会った回数でなかよし度が4段階に上がります。火の近くに座って長くいるようになり、帰りぎわにおみやげを置いていきます（全15種。図鑑「おみやげ」）。
いちばんなかよくなると、しぐさが1つ増えます。**来る確率は変わりません。**

### 天気・季節・月

- 天気（晴れ・雨・雪・霧）は数分〜十数分ごとに変わります。雨の日は薪の減りが少し早く、雪の日は景色が白くなります。設定で固定もできます
- 季節は端末の日付で決まります（春：花びら／夏：夜に蛍／秋：落ち葉／冬：雪景色）
- 月は今夜の本当の形になります（日付から計算。通信はしません）。新月のころは星が増えて天の川がうっすら見え、満月のころは夜の地面がほんのり明るくなります

### しおりと小物

図鑑の「しおり」に、やってみたいことが18個あります。期限・順番・日替わりはありません。
うまった数に応じて、焚き火のまわりに小物（丸太のいす・やかん・ランタン・マグカップ・薪棚・小さなテント）が増え、しおりのページで出し入れできます。

### 気持ちよさの仕掛け

- **くべコンボ**：0.3〜0.8秒の間隔で指でくべ続けると続きます。10・30・50・100 で火の粉が弾けます（長押しとおまかせの薪は数えません）
- **業火タイム**：「天を焦がす炎」を約40秒保つと、15秒間、**レアな出来事の確率が3倍**になります
- **予兆**：レアの直前に、まれに火元が色つきで光ります。白 ＜ 青 ＜ 赤 ＜ 金（★★以上が確定）＜ 虹（★★★が確定）。確率は変えません
- **金の薪**：手でくべるたびに 1/500 で、次の一本が金色に光ります
- **節目**：累計 100・1,000・10,000 本と、ゾロ目でお祝い
- **今日の一本・称号**：連続日数と、累計本数に応じた称号。途切れても何も失いません

### そのほか

- **寝落ちモード**：15分／30分／60分。時間に向けて火と音をゆっくり小さくし、最後は熾火と静かな画面になります
- **音のミックス**：焚き火・川・虫の声・風・雨を、それぞれ ON/OFF と音量で調整できます
- **写真モード**：UIを隠し、もう一度タップで「くべた薪 ○本」・日付・月の名前を小さく入れた画像を保存・共有できます

## 部屋（囲む火）

同じ合言葉を入れた人と、最大5人で1つの火を囲めます。**言葉は交わさず、同じ火に薪をくべ、同じ火を眺めます。** チャットはありません。文字を入れるのは、合言葉と、入れたい人だけの呼び名（6文字まで）だけです。

- **入り方**：下の「空」ボタンを長押しするか、設定 →「部屋（だれかと囲む）」。「部屋をつくる」で合言葉（ひらがなの言葉3つ。書き換え可）が提案され、コピーや共有で相手に伝えます。相手は「合言葉で入る」に同じ合言葉を入れます
  - 合言葉は、ひらがな・カタカナ・英数字の4〜24文字。カタカナとひらがな、大文字と小文字、全角と半角は同じものとして扱います
  - **合言葉を知っている人はだれでも入れます。** 最後に入った部屋の合言葉は端末の中にだけ残り、次からワンタップで入れます（記録の書き出しには含まれません）
- **呼び名**：入るときに、6文字までの呼び名を入れられます（入れなくてもかまいません）。**その部屋にいるあいだだけ**のもので、端末には保存されず、次に入るときはまた空です。入れた人は影の下に呼び名が出て、入れていない人は「だれか」と呼ばれます。写真には入りません
- **入室・退室の知らせ**：だれかが入ると「○○が火のそばに座りました（3人で囲んでいます）」、出ると「○○が席を立ちました」と画面の上に出て、ログにも残ります。アプリを閉じているあいだの通知はありません（部屋の画面を開いているときだけ）
- **出方**：チップ「部屋を出る」を1タップ。ひとりの焚き火に戻ります。**ひとりの焚き火の火力・熾・うめたものは、部屋に入る前のまま**です
- **席**：5人まで。いっぱいのときは入れません。通信が切れると席は空きます（タブを閉じればすぐ、電波が切れたときも90秒以内）。アプリを裏に回して2分たつと切断し、戻ると入り直します
- **1つの火**：火の減り方はひとりのときと同じです。火力の最大は人数で少し上がります（2人＝105、3人＝110、4人＝115、5人＝120。100を超えたぶんは炎が横に広がります）
- **自分の記録**：自分の手でくべた薪は、ひとりのときと同じく「くべた薪」に数えます（今日の一本・節目・薪の図鑑も同じ）。ほかの人の薪は数えません。部屋でくべた本数は、きろくに「部屋でくべた薪」としても出ます
- **席の影**：火のまわりに、座った人の影と、その人の灯りの色（8色から選ぶ）のランタンが見えます。顔はありません。上部の小さな点が人数です
- **しぐさ**：チップ「しぐさ」から 手をかざす／うなずく／空を指さす／あくび／おじぎ（3秒に1回まで）
- **共有の空**：天気は部屋の全員で同じです（ひとりの焚き火の天気とは別）。朝と夜は、それぞれの端末の時刻のままです
- **みんなの業火**：ゲージは部屋で1つ。人数が多いほど少し早くたまります（1人＝40秒、5人＝25秒）。満タンで全員に15秒の業火タイム
- **おすそわけ**：あぶったものを「自分で食べる」か「おすそわけ」か選べます。渡すと、相手の図鑑「あぶり」に「もらった○○」として残ります（1分に1回まで）
- **にぎやかな要素**（ひとりは静かに、部屋ではにぎやかに。言葉は使いません）
  - **薪の合いの手**：だれかがくべた直後に別の人がくべると続きます。続くほど音程が上がり、その人の灯りの色の火の粉が上がります（画面左に「合いの手 ○」。最長はきろくに残ります）
  - **せーの**：チップ「せーの」を押すと、3秒後に全員の画面で火元が光ります（輪が火元へ縮んでいきます）。その瞬間にそろってくべると、人数ぶんの色の火柱が上がります。そろわなくても、何も失いません（8秒に1回まで）
  - **まねっこ**：だれかのしぐさを、3秒以内に全員がまねると「そろった」。全員の影が小さく跳ねます
  - **業火の祭り**：みんなの業火の15秒は、全員の影が立ち上がり、くべるたびに自分の色の火の粉が噴き上がります。終わると、部屋の合計本数だけが出ます（順位は出ません）
  - 「しずか」設定の人には、光だけの控えめな見え方になります（数えるのは同じです）
- **部屋の記憶**：部屋には、燃やした本数の合計と、最後に火が入った時刻だけが残ります。間があいて入ると「3日ぶりの火です」のようにひとこと出ます。30日だれも来なかった部屋は、本数の合計以外が初期化されます
- 部屋の中では、薪の種類・組み方のチップ、熾、うめて焼く、ながめるは使いません（ひとりの焚き火のものです）。音の設定・しずか・すっきり表示・写真モードはそのまま使えます

### 囲む火の出来事（図鑑の「囲む火」ページ・全8種）

部屋の中でしか起きません。ひとりの図鑑の分母にも、炎の色の解放の条件にも入りません。その場にいた全員に記録されます。

| 出来事 | 条件 |
| --- | --- |
| 重なる手 ★ | 2人が1秒以内にくべた |
| 三つの火の粉 ★★ | 3人（または4人）が1秒以内にくべた |
| 五つの手 ★★★ | 5人全員が1秒以内にくべた |
| 火の輪 ★★ | 5人そろって、火力が110以上になった |
| 同じ星 ★★ | 部屋で流れ星が流れているあいだに、2人以上が空をタップした |
| 語らいの夜 ★★ | 3人以上で、30分のあいだ火を絶やさなかった |
| ひさしぶりの火 ★ | 7日以上だれもくべなかった部屋に、ふたたび薪をくべた |
| 千の薪 ★★ | 部屋で燃やした本数の合計が1000本を超えた |

### 部屋の中のレア（確率の説明）

- **燃えている間の抽選（10秒ごと）と訪問者**は、部屋では「火の番」（席の番号がいちばん小さい人）の端末だけが行います。つまり、部屋全体で10秒に1回です（人数ぶん増えることはありません）
- **くべたときの抽選**は、くべた人それぞれの端末で行います（ひとりのときと同じく、1人あたり毎秒1回まで）
- どちらの結果も部屋に送られ、**そのとき部屋にいた全員が見て、全員の図鑑に記録されます**（トーストに「みんなで見た」と添えます）。このため、人数が多い部屋ほど、くべたときのレアに出会う機会は増えます
- 1回あたりの確率は、ひとりのときと同じです。業火タイム中の3倍も同じです
- 夜・朝の条件は、抽選した人の端末の時刻で決まります（朝の人の画面に、流れ星が届くこともあります）
- 金の薪は、くべた本人だけの出来事です（部屋の火は満タンになります）。「？？？」の2つは、部屋の中では起きません

### 部屋で送るデータ（これで全部です）

部屋に入っているあいだだけ、Firebase（Google）の次の2つと通信します。**送るのは数字と、決められた選択肢の番号、それと呼び名（入れた場合だけ・6文字まで）だけ**です。合言葉そのものは送りません（合言葉から作った部屋のIDだけを使います）。呼び名は、同じ部屋に入った人に見えます。本名や連絡先は入れないでください。

- **Firebase Authentication（匿名ログイン）**：「その席の持ち主だけが書ける」を確かめるための、ランダムな利用者ID。名前やメールアドレスは使いません
- **Firebase Realtime Database**：下の3つ

| 場所 | 中身 |
| --- | --- |
| `rooms/{部屋のID}/seats/{0〜4}` | 利用者ID、最後に生きていた時刻、灯りの色の番号（0〜7）、座る位置（0〜4）、呼び名（入れた場合だけ・6文字まで。席を立つと消えます）、直前の動き `ev`（種類の番号 0〜15・数 1〜20・時刻） |
| `rooms/{部屋のID}/fire` | 火力（0〜120）、時刻、燃やした本数の合計、業火のゲージ（0〜1）と始まった時刻、最後に火が入った時刻 |
| `rooms/{部屋のID}/bc` | 部屋の出来事の番号（0〜31）、補助の数（0〜255）、時刻、送った席（0〜4） |

`ev` の番号：0＝くべた（数は本数）／1〜5＝しぐさ／6〜9＝おすそわけ（焼き加減。数は相手の席と食べ物の番号）／10＝流れ星をタップ／11＝せーの。
ほかに、Firebase の SDK（`www.gstatic.com`）を、部屋に入るときに読み込みます。部屋のIDは `SHA-256("takibi-room:" + 合言葉)` の先頭32文字で、部屋の一覧はだれにも読めません。

## レアな出来事（全24種）

出会うと図鑑とログ（直近100件）に残ります。

| 出来事 | 出会える条件 | 1回の抽選あたり |
| --- | --- | --- |

### 確率に関わる決まり（このアップデートでの変更）

既存のレアの確率は変えていません。変わったのは次の点だけです。

| 場面 | 変更 |
| --- | --- |
| おまかせ火の番が働いている間（ながめる中と、寝落ちタイマーの前半） | 燃えている間の抽選が **20秒ごと**（ふだんの半分の頻度）になります。1回あたりの確率は同じです。「？？？」の2つは起きません |
| おまかせの薪 | くべたときのレア抽選と、金の薪の抽選を行いません |
| 新しいレア | 天の川・月暈（各1%、条件は表のとおり） |
| 演出のつよさ・組み方・すっきり表示・少しずつひらく・画質の自動調整 | 確率には一切影響しません |

## データについて

- 保存先はブラウザの localStorage（キー：`takibi-kube.v1`）のみ。ひとりの焚き火では、外部には何も送信しません（部屋に入ったときに送るものは「部屋（囲む火）」のとおりです。記録そのものは送りません）
- 以前のバージョンの記録はそのまま引き継がれます（新しい項目は、足りないときだけ初期値で補います）
- どんな演出・機能でも、くべた本数や図鑑などの記録が消えたり減ったりすることはありません

### 記録を手元に残す（書き出し・読み込み）

記録は端末のブラウザの中にしかありません。**iPhone の Safari は、ホーム画面に追加していないサイトの記録を、しばらく開かないと消すことがあります。** 長く遊んだら、書き出しておくと安心です。

- **設定 → きろく →「記録を書き出す」**：記録を `TKB1.` で始まる1行の文字列にします。コピーするか、ファイル（`takibi-kiroku-日付.txt`）として保存・共有できます
- **「記録を読み込む」**：文字列を貼りつけ →「たしかめる」で本数・図鑑の数・書き出した日を確認 → 2回タップで置き換えます
  - 形式が合わない・壊れている・大きすぎる（200KB超）文字列は「読み込めませんでした」と出て、何も変わりません
  - 置き換える直前の記録は1世代だけ控え（`takibi-kube.v1.bak`）に残り、「ひとつ前の記録に戻す」で戻せます
- 書き出しには、寝落ちタイマーやながめるなど、その場かぎりの状態は含まれません
- 設定 →「記録をすべて消す」でいつでも初期化できます（2回タップ。控えもいっしょに消えます）

### 保存される項目

火力・くべた本数・燃やした時間・図鑑（出来事／薪／あぶり／おみやげ／しおり）・ログ・天気・連続日数・最高コンボ・設定（音・ミックス・振動・空・天気・炎の色）に加えて、このアップデートで次の項目が増えました（合計で数KB以内）。

`set.calm`（演出）／`set.view`（表示）／`set.wake`（画面をつけたままにする）／`watchLogs`（おまかせでくべた薪）／`open`（ひらいた機能）／`peak`（いちばん大きかった火力）／`news2`・`a2hs`（1回だけの案内を見せた印）／`ember`（熾）／`bury`（うめたもの）／`stack`・`stackRec`（組み方と記録）／`gifts`（おみやげ）／`colorFree`（炎の色の解放）／`shiori`・`props`・`prog`（しおり・小物・途中経過）

課金・広告・ガチャ・リセットチケットの類はありません。

## 動作について

- 画面の更新は毎秒60回まで（シートを開いている間・ながめる中・眠ったあとは毎秒30回）
- 端末が重いときは、炎・火の粉・煙・天気の粒の「出る量」だけを自動で絞ります（火力・抽選・記録には影響しません。何も表示しません）
- 画面を消さない機能（Screen Wake Lock）、共有（Web Share）、クリップボード、保存の永続化の依頼（Storage API）、振動は、使える端末でだけ使います。使えなくても遊べます
- オフライン対応（Service Worker）・通知・バックグラウンド再生・位置情報は使っていません
- 部屋は `https://`（または localhost）で開いたときだけ使えます。部屋の中では、書き込みを1人あたり平均で毎秒1回までに抑えています（くべた本数はまとめて送ります）

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `app.js` | アプリ本体（外部ライブラリ・素材ファイルなし。絵と音はすべてコードで生成） |
| `multi.js` | 部屋（囲む火）。部屋に入るときに初めて読み込まれます。Firebase の公式 SDK（13.4.0）だけを使います |
| `firebase-config.js` | Firebase の設定値。値が空のあいだは、部屋の入口が出ません |
| `database.rules.json` | Realtime Database の Security Rules（Firebase のコンソールに貼りつけるもの） |
| `tests/` | Security Rules のテスト（ゲームの動作には不要） |
| `manifest.webmanifest` / `icon*.png` / `icon.svg` | ホーム画面に追加したときの名前とアイコン |

## 部屋を動かすための設定（持ち主向け）

1. Firebase コンソールでプロジェクトを作り、**Authentication →「匿名」を有効**にする
2. **Realtime Database を作成**（場所は asia-southeast1）し、「ルール」タブに `database.rules.json` の中身を貼りつけて公開する
   - `database.rules.json` が更新されたときは、貼り直してください。呼び名は、貼り直したあとから使えます（古いルールのままでも部屋には入れますが、呼び名は「だれか」になります）
3. Authentication → 設定 →**承認済みドメイン**に、ゲームを置くドメイン（例：`<ユーザー名>.github.io`）を追加する
4. プロジェクトの設定 → ウェブアプリの構成値を `firebase-config.js` に入れる

無料プラン（Spark）で動きます。同時接続は100まで（＝5人の部屋なら20部屋ぶん）で、上限に届いているあいだは「いまは部屋につながりません」と出ます。

Security Rules のテスト（Java と Node.js が必要）：

```
cd tests
npm install
npm test
```

## 開発メモ

URLの末尾に `?debug` を付けると、ブラウザのコンソールから演出や状態を確認できます（プレビューは図鑑に記録されません）。

- `takibi.ids`：`takibi.fx(id)` で出せるIDの一覧
  - レアな出来事のID、`wood-cedar` など、`roast-marsh` / `roast-imo`、`bury-best` など、`wx-rain` / `wx-snow` / `wx-fog` / `wx-clear`、`season-spring` など
  - `fever`、`combo`、`milestone`、`gold`、`omen-white` 〜 `omen-rainbow`、`calm-on` / `calm-off`
  - `watch` / `watch-end`、`sleep`（20秒の短縮版）、`photo`、`away`、`news`、`a2hs`
  - `stack-igeta` など、`friend-kitsune` など（いちばんなかよくなったときのしぐさ）、`gift`、`shiori`、`props-all` / `props-none`
  - `open-all` / `open-none`（少しずつひらく）、`q-low` / `q-auto`（画質の段階）
  - `continue`、`gameover`（`gameover` のプレビューは画面を5回タップすると抜けられます）
- `takibi.fuel(0〜100)` / `takibi.ember(0〜100)`：火力・熾を指定
- `takibi.skip(分)`：時計を進める（その間アプリを閉じていたものとして扱う）。負の値で時計を戻せます
- `takibi.moon(0〜1)`：月の形を指定（0＝新月、0.25＝上弦、0.5＝満月、0.75＝下弦。`null` で元に戻す）
- `takibi.pick('log')` / `takibi.pick('amb')`：抽選を1回だけ行ってIDを返す（確率の確認用。何も起こしません）
- `takibi.room.fake(人数)`：通信せずに、架空の仲間（自動でくべる・しぐさをする）と部屋に入る。`takibi.room.leave()` で出る。`takibi.room.state()` で部屋の状態
  - 部屋の演出は、部屋を1度ひらいたあとに `takibi.fx('m-itsutsu')` など（`m-kasanaru` / `m-mitsu` / `m-itsutsu` / `m-hinowa` / `m-onajihoshi` / `m-katarai` / `m-hisashiburi` / `m-sen`）、しぐさは部屋の中で `gest-1` 〜 `gest-5`、せーのは `room-seeno`、業火の祭りは `room-fest`
  - URL に `?debug&emu` を付けると、ローカルのエミュレータ（`cd tests && npx firebase emulators:start --only database,auth --project demo-takibi`）につなぎます
- `takibi.counts()`：fps・画質の段階・粒子数・キャンバスの数・保存データの大きさなど
